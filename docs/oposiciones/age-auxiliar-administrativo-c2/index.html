Pruebas y examen

    Texto oficial
    «El proceso de selección estará formado por un ejercicio único, que constará de las dos partes que a continuación se indican»BOE-A-2025-26262 · publicado el 22/12/2025
  • Tiempo máximo: 90 minutos
    Texto oficial
    «El tiempo máximo para la realización de este ejercicio será de noventa minutos.»BOE-A-2025-26262 · publicado el 22/12/2025
  • Cada error descuenta un tercio; en blanco no penaliza
    Texto oficial
